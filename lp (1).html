なぜ、このツールを
作ったのか

自分の縦書きのオリジナル脚本を国際映画祭にエントリーするために、Fountain形式の脚本に置き換えなければならなかった。それがこのツールとの最初の出会いです。
— 花堂純次　映画監督 / CLEO顧問

日本語の脚本は縦書きが基本です。しかし、世界の映画祭やプロデューサーに脚本を提出するとき、求められるのは欧米標準のFountain形式。Final Draft、WriterDuet、Highland 2――これらのソフトで開けるフォーマットです。

この変換作業は、これまで手作業か、専門ソフトに頼るしかなかった。しかし今、AIがその仕事をやってくれます。しかも無料で、ブラウザだけで、長編脚本でも。

ニッチな世界かもしれない。でも、このツールが一人でも多くの日本の映画人の「世界への扉」になればと思い、オープンに公開することにしました。

Before / After

同じシーンが変換前後でどう変わるか、日本語Fountain版と英語翻訳版を切り替えて比較できます。

BEFORE — 日本語原稿
１　漁港・外部・夜明け 海霧の中、古びた漁港。波の音だけが響いている。 ケンジ（50代、無精髭）がコンテナに背を預けて煙草を吸っている。 マリコ「（息を切らせて）まだいたの。」 ケンジ「どこにも行けない。」 長い沈黙。 ケンジ「（静かに）俺が殺したんだ。」
AFTER — Fountain（日本語）
EXT. 漁港 - 夜明け 海霧の中、古びた漁港。波の音だけが響いている。 ケンジ（50代、無精髭）がコンテナに背を預けて煙草を吸っている。 MARIKO (息を切らせて) まだいたの。 KENJI どこにも行けない。 長い沈黙。 KENJI (静かに) 俺が殺したんだ。 FADE OUT.
AFTER — Fountain（英語翻訳）
EXT. FISHING PORT - DAWN Sea mist shrouds the weathered harbor. Only the sound of waves echoes. KENJI, 50s, unshaven, leans against a container smoking a cigarette. MARIKO (breathless) You're still here. KENJI I have nowhere to go. A long silence. KENJI (quietly) I killed him. FADE OUT.
ゴールド = シーン柱　　白 = キャラクター名・台詞　　グレー = ト書き
使い方

3ステップで
完了

01
APIキーを取得する
AnthropicまたはGoogleのAPIキーを取得します。どちらも無料でアカウント作成でき、少額のチャージで使い始められます。脚本1本の変換コストは数十円程度です。
console.anthropic.com または aistudio.google.com
02
脚本を貼り付ける
日本語の脚本をそのまま左のエリアに貼り付けるだけ。長編2時間の脚本も、自動的に分割して処理します。出力言語（英語翻訳 / 日本語のままFountain化）も選べます。
03
CONVERTを押す
ボタンを押すだけで変換完了。右側にFountain形式で出力されます。コピーするか、.fountainファイルとしてダウンロードして、Final DraftやWriterDuetに読み込んでください。

Mac専用 / 無料
BEAT
シンプルでさくさく動く、Fountain形式の脚本執筆アプリ。自動シーンナンバリング、Final Draft形式のインポート/エクスポート、PDFエクスポート、ナイトモード、文字数・シーン統計（ジェンダー分析機能含む）を搭載。これを作ったのが現役の脚本家というのが、触ってみるとよくわかる。

Windows / Mac 両対応
Afterwriting

BEATはMac専用ですが、WindowsユーザーにはAfterwritingがおすすめです。インストール不要、ブラウザで開くだけ。しかも日本語も文字化けしません。

Windows / Mac / Linux 対応 / 無料
AFTERWRITING
Fountain形式またはFinal Draft形式で書かれた脚本を開いて編集できるブラウザベースのエディタ。インストール不要でWindows・Mac・Linuxどこでも動きます。日本語の文字化けもなく、このFountain Converterで変換した.fountainファイルをそのまま開いて編集できます。

重要：あなたの脚本データはPC外部に送信されません。完全クライアントサイドで動作するため、脚本の内容はローカルのみで処理されます。
Windows / Mac / Linux インストール不要 日本語対応 Fountain / FDX対応 PDFエクスポート Dropbox連携 オフライン版あり 完全無料
